CLIMAGESTÃO - MVP
Abra index.html no navegador.
Os dados ficam salvos localmente no navegador (localStorage).
Funcionalidades: dashboard, clientes, orçamento com cálculo de margem, impressão, ordens de serviço e financeiro.
Para produção: adicionar banco de dados, login, backup em nuvem, emissão fiscal, WhatsApp/API, estoque, agenda e permissões de usuários.
